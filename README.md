# ai-saas-api-support-postman
A production-style Postman test suite for validating and troubleshooting an AI SaaS API workflow.


## Notes
This project uses the DummyJSON mock API to demonstrate professional API Support Engineering workflows.
Some create, update, and delete operations are simulated by the API and are not permanently persisted. The collection is designed to validate API behavior while accurately reflecting the capabilities of the mock service.
