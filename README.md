# AI SaaS API Support Suite
A production-style Postman project that demonstrates how an AI Support Engineer validates, tests, and troubleshoots REST APIs used in SaaS applications.

This project simulates real-world API support workflows using Postman and the DummyJSON mock API. It showcases authentication, automated API testing, environment management, data-driven testing, workflow validation, technical documentation, and troubleshooting techniques commonly used by AI Support Engineers and SaaS Technical Support teams.



## Notes
This project uses the DummyJSON mock API to demonstrate professional API Support Engineering workflows.
Some create, update, and delete operations are simulated by the API and are not permanently persisted. The collection is designed to validate API behavior while accurately reflecting the capabilities of the mock service.

## Key Features

- Authentication workflows (Login & Logout)
- REST API request validation
- Automated JavaScript test scripts (`pm.test`)
- Environment variable management
- Response and status code validation
- Collection Runner automation
- Data-driven testing using CSV files
- Workflow validation
- Troubleshooting guide
- Professional API documentation
